## 🚀 使用方法

1. **下载** `GameTogether_vX.X.X.zip`
2. **解压**到任意文件夹（**建议纯英文路径**，如 `D:\GameTogether\`）
3. **双击** `GameTogether.exe` 运行
4. 如果 Windows 提示"未知发布者"，点 **"更多信息"** → **"仍要运行"**
5. 各页面操作提示：
   - 点 **卡片封面** 查看游戏详情
   - 点 **夸克** 弹出二维码（手机扫码保存）
   - 点 **迅雷** 弹出链接窗口（复制后用迅雷下载）
   - 点 **★** 收藏游戏

## ❓ 常见问题

**Q：Windows 提示"未知发布者"怎么办？**

A：点 **"更多信息"** → **"仍要运行"**。这是因为程序未做代码签名，不影响使用。

**Q：程序无法启动 / 提示缺少 DLL？**

A：请确保解压到**纯英文路径**下。如果路径有中文，可能导致部分组件加载失败。

**Q：点击更新后程序没变化？**

A：请检查网络是否畅通。如果问题持续，请手动下载最新版覆盖。

**Q：会员 CDKey 怎么获取？**

A：游戏盒子内部赞助获取.

**Q：换电脑后会员还能用吗？**

A：不能。CDKey 与硬件绑定，一机一码，换机 / 重装系统后失效，请谨慎操作。

**Q：资源链接失效怎么办？**

A：客服微信:GameTogether1,联系客服修复
